\section*{Вопросы к экзамену \enquote{Алгоритмические основы робототехники}}

\begin{flushright}\begin{small}Юрий Литвинов\\\small{y.litvinov@spbu.ru}\end{small}\end{flushright}

Экзамен проводится в формате блиц-опроса, без подготовки. Задаётся два вопроса и, возможно, уточняющие вопросы. Оценка ставится так:

\begin{enumerate}
    \item В случае, если на хотя бы один из вопросов ответ неудовлетворителен, за курс выставляется оценка \enquote{неудовлетворительно} (ECTS F).
    \item Оценки за ответы на вопросы складываются.
    \item К полученной оценке прибавляется оценка за доклад.
    \item Итоговый процент освоения дисциплины рассчитывается по формуле MAX(0, <сумма оценок> - 5) * 10.
    \item Далее применяется стандартная шкала ECTS.
\end{enumerate}

\textbf{Вопросы:}

\begin{enumerate}
    \item State-of-the-art в беспилотных автомобилях. Поколения/уровни автопилотов. 
    \item ADAS: задачи, платформы, датчики и алгоритмы.
    \item Степень мобильности, степень управляемости и степень маневренности робота, степени свободы, голономность. Управление движением.
    \item Колёсные роботы, виды колёс, конфигурации колёс, достоинства и недостатки.
    \item Кинематическая модель трёхколёсного робота с дифференциальным управлением.
    \item Устройство сенсоров: энкодеры, гироскопы, датчики расстояния.
    \item Датчики карты глубин: лидары, структурированный свет, стереопары.
    \item Наземные маяки, RF-метки, спутниковые навигационные системы.
    \item Точность измерения и ошибка (систематическая, случайная), представления погрешности измерений, распространение ошибки.
    \item Основные алгоритмы технического зрения: depth from focus, оптический поток, стереозрение, structure from motion, ZLoG.
    \item Сегментация изображений.
    \item Архитектуры систем навигации.
    \item Представление карты (непрерывное, дискретное с точной декомпозицией, с фиксированной и адаптивной сеткой, топологическое представление).
    \item SLAM, существующие алгоритмы.
    \item Behavior tree.
    \item Алгоритмы Bug 1 и Bug 2.
    \item Архитектура ROS 2.
    \item GPIO, SPI, UART, RS485.
    \item Шины I2C, CAN.
    \item Обзор робототехнических симуляторов.
\end{enumerate}
